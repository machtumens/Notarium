## Overview

Add a Primer feature: the user types a topic string and receives a structured "catch up before class" primer generated by DeepSeek — an overview, a list of key concepts, and a list of priming questions to think about before class. Topic-string input only: no note context, no DB reads/writes, no session storage. New backend endpoint `POST /api/ai/primer` (auth-gated, rate-limited) + new `PrimerPage.tsx` frontend, discoverable via a "Prep for class" card on `TodayPage`.

**FORK LOCKED (this session):** topic-string input only. No DB reads. No `notes.extracted_text` context injection. No session/local storage — generation is fully ephemeral; a refresh clears the result.

Phase 5 depends on Phase 3 (✅ COMPLETE — AppShell/routing settled). It shares 6 files with Phase 4 (`ai.ts`, `index.ts`, `api.ts`, `types/index.ts`, `AppRoutes.tsx`, `lazyPages.ts`) and is explicitly sequenced to EXECUTE after Phase 4's EXECUTE has committed those files — Phase 5 is the 2nd consumer of the `/api/ai/*` URL prefix Phase 4 introduces (first: `/api/ai/quiz`; second: `/api/ai/primer`).
