## Overview

Add a Primer feature: the user types a topic string and receives a structured primer (overview, key concepts, study tips) generated by DeepSeek. This is a lightweight "catch up before class" tool. Topic-string input only — no DB reads, no note context. New backend endpoint `/api/ai/primer` + new `PrimerPage.tsx` frontend.

**FORK LOCKED:** topic-string input only. No DB reads. No `notes.extracted_text` context injection. No session storage.

Phase 5 depends on Phase 3 (routing structure with AppShell in place, label "Community" settled). Independent of Phase 4 (no shared files unless both touch backend/src/routes/ai.ts and backend/src/index.ts in the same session — sequence Phase 5 after Phase 4 if possible to avoid conflicts).
